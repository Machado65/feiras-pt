# Feiras PT

Calendário de feiras tradicionais e gastronómicas em Portugal, revisto todas as semanas por uma routine do Claude na cloud.

Subscrever: <https://machado65.github.io/feiras-pt/feiras.ics>

Os dados estão em `feiras.json`; o `CLAUDE.md` explica os critérios, o formato e o procedimento semanal.
